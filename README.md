# Hand-Press Bibliography

Two browser-based teaching tools on early modern printing and bibliography.

- `printing-house/` – Hand-Press Printing House: composing, imposition, presswork and folding.
- `collation/` – Collational Formula Workbench: building collational formulas in Bowers's notation.

No build step and no dependencies. Open `index.html` locally, or publish the folder with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).
